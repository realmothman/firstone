# Titia Fofa Simulation

Simulação simples da rotina da Titia Fofa com barras de progresso para peso e energia.

## Uso

```bash
python main.py
```

## GitHub Pages

Habilite o GitHub Pages nas configurações do repositório para servir a pasta `docs/`. Em seguida, acesse

```
https://<seu-usuario>.github.io/firstone/
```

para executar a simulação diretamente no navegador.
